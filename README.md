# Mice Engine
An open-source 2D game engine focused on creating entirely procedural games, where graphics, animations, and audio are generated mathematically, with the goal of producing extremely lightweight and compact games.

## Dependencies
- OpenGL
- GLAD
- SDL
- GLM
- Dear ImGui
- Imnodes
